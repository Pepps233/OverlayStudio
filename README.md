## About

Overlay Studio is an open-source LinkedIn banner generator with a drag-and-drop editor. Overlay Studio lets you create professional, eye-catching banners with custom backgrounds, overlays, and cosmetic elements.

## Features

- **Make it yours**: Choose a background or upload your own images.
- **Add some personality**: Decorate your banner with animals, hats, and other accessories.
- **Arrange your design**: Drag, resize, rotate, and layer images to get the look you want.
- **Preview as you create**: See your banner take shape as you make changes.
- **Download your banner**: Save your finished design as a PNG or JPEG.

## Local Host

To run Overlay Studio on your computer, install [Node.js](https://nodejs.org/) 24 LTS (which includes npm):

1. **Clone the project and open its folder:**
   ```bash
   git clone https://github.com/Pepps233/OverlayStudio.git
   cd OverlayStudio
   ```

2. **Install the project packages:**
   ```bash
   npm ci
   ```

3. **Start the local server:**
   ```bash
   npm run dev
   ```
